Detailed Description

Experimental message runtime over WebSocket and WebRTC DataChannel.

One peer represents one WebSocket connection or one WebRTC DataChannel. Callbacks run on the transport's reactor thread. Input, decoded JSON, and allocations made with cwist_livemsg_alloc() remain valid until respond() returns. A peer pointer must not be retained after on_disconnect().
