Detailed Description

Content-hashed in-memory assets: registration, URL lookup and serving.

Assets are immutable once published. A registry is a newest-first singly linked list whose head is swapped in atomically, and nodes are only freed with the app, so a request that resolved an asset can keep using it while another thread registers more.
