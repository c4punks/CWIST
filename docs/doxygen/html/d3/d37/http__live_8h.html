Detailed Description

Classic-pool connection registry hooks for shutdown (private).

A classic pool worker registers the connection it serves. Handlers bracket the blocking wait for the next request on a keep-alive connection with cwist_http_live_idle_enter()/_leave(), so shutdown can close idle connections at once and let in-flight requests finish. Outside a classic pool worker both calls are no-ops.
