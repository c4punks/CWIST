cwist_middleware_func cwist_mw_jwt_auth ( const char *  secret)

JWT authentication middleware factory.

Reads the Authorization header, expects "Bearer <token>". On success the decoded claims are available via cwist_mw_jwt_get_claims(). On failure responds with 401 Unauthorized and short-circuits the chain.

Parameters
secretHMAC-SHA256 signing secret (null-terminated, must outlive the middleware invocations - typically a static/global string).
Returns
Middleware function pointer, or NULL when secret is NULL or eight distinct secrets are already registered in this process.

JWT authentication middleware factory.

Parameters
secretBorrowed signing secret used to verify bearer tokens.
Returns
Middleware wrapper bound to the supplied secret, or NULL on overflow.
