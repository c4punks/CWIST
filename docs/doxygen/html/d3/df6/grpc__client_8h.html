Detailed Description

HTTP/2-based gRPC client (h2c cleartext, or TLS with ALPN "h2").

One active call per connection: cwist_grpc_call_start() fails while another call on the same client is still open. Payloads are opaque serialized protobuf messages; the 5-byte gRPC framing is applied here.

Block until response headers arrive or the stream ends.

Pump until the call's response headers arrive or the stream ends. Returns 0 when Response-Headers were received (the call is committed, gRFC A6), 1 when the stream ended first (status available via cwist_grpc_call_finish), -1 on bad arguments. Queued messages stay buffered for cwist_grpc_call_recv().

Parameters
callThe call.
Return values
0Response headers received (the RPC is committed).
1The stream ended before any response headers (retryable).
-1Invalid call, error, or deadline.

Start a unary call (no previous-attempt marker).

Start a call to a full method path ("/package.Service/Method"). request is one serialized protobuf message (may be NULL/0); it is framed and sent with END_STREAM, so the call covers unary and server-streaming methods. timeout_ms maps to the grpc-timeout header and is also enforced locally: on expiry the stream is reset and the call ends with CWIST_GRPC_DEADLINE_EXCEEDED. Returns NULL on failure (including when another call on this client is still active).

Parameters
cClient; must be connected and have no active call.
methodgRPC method path (e.g. "/pkg.Service/Method").
requestRequest message bytes; may be NULL when request_len is 0.
request_lenRequest length in bytes.
timeout_msPer-call deadline in ms; 0 means no deadline.
Returns
The started call, or NULL on invalid arguments, a busy/dead client, or a transport error while sending.

Start a unary call, with a gRFC A6 retry-attempt marker.

cwist_grpc_call_start() variant that attaches the standard "grpc-previous-rpc-attempts" header (gRFC A6) when previous_attempts is non-zero. Used by the channel retry engine; plain callers want cwist_grpc_call_start().

Sends HEADERS (:method POST, :scheme, :path, :authority, content-type, te) followed by the framed request message, then commits the call as the client's active call. Serialized by the client mutex: one active call per connection.

Parameters
previous_attemptsValue for grpc-previous-rpc-attempts; 0 omits the header.
Returns
The started call, or NULL on invalid arguments, a busy/dead client, or a transport error while sending (state is cleaned up).
