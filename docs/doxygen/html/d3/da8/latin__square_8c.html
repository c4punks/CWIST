Detailed Description

◆ cwist_latin_family_create()

cwist_latin_family_t * cwist_latin_family_create ( uint32_t  order,
uint32_t  min_squares 
)

Build a family of at least min_squares MOLS of order order.

The family is the MacNeish direct product of one family per prime-power factor q of order:

  • q = 2^e: L_k(r, c) = k*r + c over GF(2^e), q - 1 squares;
  • q = p prime: L_k(r, c) = (k*r + c) mod p, p - 1 squares;
  • q = 9: the order-9 orthogonal pair from Choi Seok-jeong's Gusuryak;
  • other q = p^e: the same linear rule digit-wise over (Z_p)^e, p - 1 squares. The family therefore holds min(q_i - 1) squares over the factors (p - 1 for odd prime powers with e > 1). Orders that are 2 mod 4 get a single Latin square: orthogonal pairs exist for every order except 2 and 6, but this module does not construct them for orders 2 mod 4.
Parameters
orderOrder n, 2 <= n <= CWIST_LATIN_MAX_ORDER.
min_squaresMinimum number of squares required (0 is treated as 1).
Returns
New family, or NULL when the order is out of range, fewer than min_squares squares can be built, or allocation fails.

uint32_t cwist_latin_oa_level ( const cwist_latin_family_t *  family,
uint64_t  run,
uint32_t  factor 
)

Level of factor factor in run run of OA(n^2, count + 2, n, 2).

Run i is the cell (r, c) = (i / n, i % n). Factor 0 is r, factor 1 is c, and factor j >= 2 is the symbol of square j - 2 at (r, c).

Returns
The level in [0, order), or UINT32_MAX when out of range.
