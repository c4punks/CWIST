Parse a multipart/form-data body into a field list.

Parse a multipart/form-data body.

Runs the multipart-parser-c state machine over body with boundary (the boundary without leading dashes). On malformed or truncated input the parser stops early and NULL is returned, with all intermediate state freed.

Parameters
bodyRaw body bytes; must not be NULL.
body_lenLength of body in bytes.
boundaryMIME boundary string, without the leading "--".
Returns
Newly allocated cwist_multipart_result on success (caller owns it, release with cwist_multipart_result_destroy), NULL on invalid arguments, malformed input, or allocation failure.
