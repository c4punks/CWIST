Detailed Description

Refcount-free cached response blob, reclaimed via libttak EBR.

Readers hold the blob between cwist_bdr_get_pinned() and cwist_bdr_unpin(); writers replace it with a single atomic exchange and retire the predecessor across an epoch boundary, so a swapped-out blob is never freed while a reader still serves it. mem is the backing allocation released with free_fn (cwist_free for internally learned blobs, a user-supplied releaser for callback-provided buffers).
