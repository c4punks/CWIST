Detailed Description

Runtime OpenAPI 3.1 endpoint (#408).

cwist_app_enable_openapi() mounts a GET route whose context is the app's document state: metadata plus cwist_openapi_annotate() entries. Every request walks the live route table, so a route added anywhere shows up with its path and method; annotations only add a summary and tags.

The route owns the state and frees it with the app. A small registry maps the app back to its state so cwist_openapi_annotate() can find it.

Serve the app's OpenAPI 3.1 document.

Registers GET json_path. The document lists every HTTP route of app at request time (the spec route itself and WebSocket routes excepted), so routes added before or after this call are all included. A second call on the same app is ignored.

Parameters
appApplication to serve the document from.
json_pathURL path of the document; NULL means "/openapi.json".
metaDocument metadata; NULL uses the defaults.
