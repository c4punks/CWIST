void cwist_config_load_file ( cwist_config *  cfg,
const char *  path 
)

Load key/value pairs from a simple properties-style file. Each non-blank, non-comment line must be key=value. Leading/trailing whitespace around keys and values is trimmed, and a value wrapped in double quotes is unquoted. Lines starting with '#' and lines without '=' are skipped. If the file cannot be opened, nothing is loaded.

Load a configuration file.

Parameters
cfgConfig store; NULL is accepted and ignored.
pathPath of the file to load; NULL is accepted and ignored.
