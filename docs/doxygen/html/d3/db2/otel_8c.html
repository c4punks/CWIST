Detailed Description

OpenTelemetry tracing middleware (#402).

The middleware records one SERVER span per request and pushes it onto a bounded ring; a background thread drains the ring in batches and POSTs them to the collector as OTLP/HTTP JSON. Export is fail-open: a full ring drops its oldest span and a failed POST drops the batch, so the collector never slows or fails a request.

The exporter thread is started by the first span a process records, and a pthread_atfork child hook forgets the parent's thread and spans, so every worker process exports its own spans.

◆ cwist_mw_otel_trace()

cwist_middleware_func cwist_mw_otel_trace ( const cwist_otel_cfg_t *  cfg)

OpenTelemetry tracing middleware.

Records one SERVER span per request covering the rest of the chain, with the method, path, status and start/end time, and exports the spans to the collector as OTLP/HTTP JSON from a background thread in each worker process. A valid W3C traceparent header makes the span a child of the caller's span; otherwise a new trace starts.

Export is fail-open: a full queue drops its oldest span and a failed export drops the batch; requests are never slowed or failed by the collector.

There is one exporter per process: the first call fixes the configuration and later calls return the same middleware.

Parameters
cfgExporter configuration, or NULL for the defaults.
Returns
The middleware, or NULL when memory could not be had.
