bool cwist_db_pool_destroy_timeout ( cwist_db_pool_t *  pool,
int  timeout_ms 
)

Close a pool, waiting up to timeout_ms for leased connections.

Parameters
poolPool to destroy; must not be NULL.
timeout_msWait limit in milliseconds, or -1 to wait indefinitely for all connections to be released.
Return values
trueAll connections were released and the pool (and every connection) was closed and freed.
falseThe wait timed out with connections still leased; the pool is left alive and closing, so further acquires fail and the caller must retry the destroy. Thread-safe.
