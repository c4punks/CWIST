Detailed Description

HTTP/2 wire integers in network byte order (private).

RFC 9113 frames carry 24-bit lengths, 16-bit setting identifiers, 32-bit error codes and setting values, and 31-bit stream identifiers and window increments whose top bit is reserved (sent as 0, ignored on receipt).
