Adopt a heap buffer, taking ownership without copying.

buf must come from cwist_alloc (or compatible) with room for a NUL at buf[len]; the sstring frees it on destroy/reassign. The previous contents are released.

Adopt a heap buffer, taking ownership without copying.

Parameters
strTarget string object; any owned buffer it holds is released.
bufcwist_alloc'd buffer with room for a NUL at buf[len]; ownership transfers to the string (freed on destroy/reassign). NULL clears.
lenPayload length in bytes.
Returns
ERR_SSTRING_OKAY on success, or ERR_SSTRING_NULL_STRING for NULL input.

< adopted buffer size is unknown beyond len + NUL

cwist_error_t cwist_sstring_borrow ( cwist_sstring *  str,
const char *  data,
size_t  len 
)

Borrow an external buffer without copying.

The sstring points at data (which must outlive the sstring, e.g. a string literal or arena chunk) and never frees it. The first mutating call transparently detaches the contents into owned heap storage, so borrowed strings stay fully mutable from the caller's perspective.

Borrow an external buffer without copying.

Parameters
strTarget string object; any owned buffer it holds is released.
dataBorrowed bytes; must outlive the string (literal, arena chunk, ...).
lenLength of the borrowed bytes.
Returns
ERR_SSTRING_OKAY on success, or ERR_SSTRING_NULL_STRING for NULL input.
Note
The first mutating call detaches the contents into owned heap storage, so the borrowed source is never written through.

< borrowed capacity is unknown until detach
