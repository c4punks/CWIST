Auto-detect an RDBMS on a local port and mount its runtime on an app.

Auto-detect and mount an RDBMS runtime by probing a TCP port.

Probes port via cwist_rdbms_probe_port(); on success the detected provider's runtime is mounted with cwist_rdbms_mount_runtime().

Parameters
appApp to attach the runtime to; must not be NULL.
portTCP port on localhost to probe.
Returns
true if detection and mounting succeed, false otherwise.

Allocate and attach an RDBMS runtime record to an app.

Mount an RDBMS runtime for the given provider and port.

Idempotent: if app already has an RDBMS runtime mounted, this returns true without allocating. On success the new runtime is stored in app->rdbms with ready set to true.

Parameters
appApp to attach the runtime to; must not be NULL.
providerDetected provider stored in the runtime.
portPort the provider was detected on.
Returns
true if a runtime is mounted, false on NULL app or allocation failure.

cwist_rdbms_provider_t cwist_rdbms_probe_port ( int  port)

Probe a TCP port on 127.0.0.1 to detect the RDBMS provider.

Probe a TCP port for an RDBMS wire protocol.

Connects to the given port with a 2-second send/recv timeout, inspects any unsolicited handshake bytes as a MySQL/MariaDB handshake, and if that does not match, sends a PostgreSQL StartupMessage and waits for an AuthenticationRequest response.

Parameters
portTCP port on localhost to probe.
Returns
Detected provider (CWIST_RDBMS_MYSQL, CWIST_RDBMS_MARIADB, or CWIST_RDBMS_POSTGRES) or CWIST_RDBMS_NONE if detection fails. The socket is always closed before returning.
