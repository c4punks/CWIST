Detailed Description

Declarative Schema Validation and Type-Safe Binding for CWIST.

Provides a _Generic-driven dispatch layer that maps JSON/Form payloads directly into user-defined C structures with zero-copy semantics where possible. Validation rules (REQUIRED, MIN/MAX, REGEX, EMAIL) are evaluated at bind-time and automatically produce 400 Bad Request responses with descriptive JSON error payloads on failure.

Bind a JSON payload to a user struct according to a schema.

The JSON body of req is parsed once and then each field in schema is extracted, validated, and written into out at the specified offset.

On validation failure the function returns false and populates result with per-field error messages. The caller can then pass result to cwist_bind_write_error_response() to emit a 400 response.

Parameters
reqHTTP request whose body contains the JSON payload.
schemaBind schema describing the target struct layout.
outPointer to the user struct to populate.
result[out] Detailed validation result.
Returns
true when every field passes validation and the struct is filled.

Bind a JSON payload to a user struct according to a schema.

Each schema field is looked up in the parsed JSON body, validated against its rules, and converted into the struct field at f->target_offset. The output struct is written even for fields with no matching key (zero values are written for missing fields).

Parameters
reqHTTP request whose body contains JSON text; may be NULL.
schemaDeclarative field schema; must not be NULL.
outDestination struct; must not be NULL.
resultAccumulator for validation errors; reset at start.
Returns
true when every field passed validation, false otherwise.
Return values
trueResult is valid and out is fully written.
falseresult contains one or more field errors.
