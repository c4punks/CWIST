void cwist_app_healthz ( cwist_http_response *  res)

Serve the /healthz HTTP endpoint as a JSON response.

Populate an HTTP response with the healthz JSON payload.

Runs all registered probes and writes a JSON body with an overall "status" field and a "probes" array of per-probe name, status, and optional message. The response Content-Type is set to application/json.

Parameters
resResponse to fill; NULL is a no-op. The body and headers are (re)assigned on success.

Register or update a health probe.

Register a custom probe function.

If a probe with the same name is already active, its function and context are replaced in place. Otherwise the probe is appended to the registry.

Parameters
nameProbe name; must be non-NULL and outlive the registration.
fnProbe function; must be non-NULL.
ctxOpaque context passed to fn on each evaluation.
Returns
true on success, false if name or fn is NULL or the registry is full.

Run all active probes and aggregate their results.

Evaluate all probes and return the aggregate status.

Probes are evaluated in registration order. The overall status is FAIL if any probe reports FAIL, DEGRADED if at least one reports DEGRADED and none report FAIL, and OK otherwise.

Parameters
out_probesOptional array receiving per-probe results; at most max_probes entries are written.
max_probesCapacity of out_probes.
out_countOptional output receiving the number of active probes evaluated.
out_overallOptional output receiving the aggregated status.

void cwist_healthz_unregister ( const char *  name)

Deactivate a registered health probe.

Unregister a previously registered probe.

Marks every active entry with the given name as inactive; inactive entries are skipped by cwist_healthz_run and their slots may be reused by cwist_healthz_register. The name and function pointers are not cleared.

Parameters
nameProbe name to remove; NULL is a no-op.
