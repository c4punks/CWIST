Detailed Description

Request-scoped arena allocator backed by libttak arena generations.

Wraps ttak_arena_env_t / ttak_arena_generation_t so a request/response cycle can bump-allocate its fixed-size structures from a single generation buffer and release them all in one shot instead of freeing each node.
