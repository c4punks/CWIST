Deep-copy a registry (used when an app is cloned).

Deep-copy a registry for a detached sub-app. 0 on success (NULL copies to NULL).

Copies the prefix and every asset, preserving newest-first order. On failure *dst stays NULL and no partial registry is left behind.

Parameters
dstReceives the new registry; set to NULL first.
srcRegistry to copy; may be NULL, which is treated as empty.
Returns
0 on success, -1 on allocation failure.

Match an HTTP request to a registered asset.

Resolve a GET/HEAD request path to a registered asset.

Only GET and HEAD requests under the registry prefix are considered. A request for a hashed (immutable) URL takes precedence over a logical name.

Parameters
appApp instance; must not be NULL.
reqRequest to match; path must be present.
outFilled with the matched asset and its immutability flag on match.
Returns
true on a match, false otherwise.

Fill a response for a matched asset.

Fill res for a matched asset (200, or 304 on a matching If-None-Match).

Always sets ETag and Cache-Control; honors If-None-Match with 304 and an empty body. The body points directly at the asset data, which stays alive until the app is destroyed.

Parameters
reqRequest being answered.
resResponse to fill.
matchMatch from cwist_assets_match(); if NULL or without an asset, the response status is set to 500.
