Borrow the underlying cnats connection.

Supported since v3.8. Used by opt-in extensions built on top of the bundled cnats client (e.g. the durable job queue's JetStream backend). Ownership stays with the cwist_nats_t handle; do not destroy the returned connection.

Borrow the underlying cnats connection.

The returned pointer is owned by the handle and remains valid until cwist_nats_destroy is called.

natsHandle to query, or NULL.

Subscribe to a subject.

Subscribe to a subject.

Replaces any existing subscription on the handle: the previous subscription is destroyed before the new one is created. The callback is invoked from the NATS delivery thread via cwist_nats_adapter.

Parameters
natsHandle with an active connection; must not be NULL.
subjectSubject to subscribe to; must not be NULL.
cbCallback invoked for each incoming message; may be NULL.
ctxOpaque pointer passed back to cb.
Returns
cwist_error_t with err_i16 set to 0 on success, CWIST_ERROR_INVALID_PARAM on NULL arguments, or the natsStatus code on failure.
