◆ cwist_io_queue_stop()

void cwist_io_queue_stop ( cwist_io_queue *  q)

Request that all runners stop processing without freeing the queue.

This is useful when the queue is shared by worker threads: callers can stop the runners, join the threads, and then destroy the queue safely.

Parameters
qQueue handle.

Request that all runners stop processing without freeing the queue.

Parameters
qQueue instance to stop.

Request that all runners stop processing without freeing the queue.

Runners finish the jobs already submitted, then return. The descriptor stays open until cwist_io_queue_destroy(), so a runner blocked in kevent() is woken by the wake event rather than by a close() that BSD kernels need not notice.

Parameters
qQueue handle to stop.
