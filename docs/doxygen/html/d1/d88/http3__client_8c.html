◆ H3C_RECV_BATCH

#define H3C_RECV_BATCH   64

Run one iteration of the QUIC I/O loop.

Computes how long lsquic wants to wait until its next timer (bounded to [0, 1s]), polls the UDP socket for that interval, feeds any received datagram into lsquic_engine_packet_in(), and finally runs lsquic_engine_process_conns() to advance all connections.

Parameters
clientThe HTTP/3 client whose engine and socket are polled.
timeout_msDesired poll timeout in milliseconds; values <= 0 fall back to 1 ms.

◆ cwist_http3_client_enable_datagram_channel()

int cwist_http3_client_enable_datagram_channel ( cwist_http3_client *  client,
int  enabled 
)

Use raw datagrams and WebTransport on the same connection.

Enables raw datagrams (as cwist_http3_client_enable_datagrams()) while keeping WebTransport and HTTP Datagrams (RFC 9297) on. Per connection:

  • if the peer does not enable HTTP Datagrams, raw payloads are sent and received as plain RFC 9221 DATAGRAM frames;
  • if it does, every DATAGRAM frame carries a quarter stream ID, so the first cwist_http3_client_send_datagram() opens a datagram channel, an extended CONNECT stream with :protocol CWIST_HTTP3_DATAGRAM_PROTOCOL, and raw payloads travel both ways as HTTP Datagrams on it. WebTransport datagrams stay on their session's stream and never mix with them. The channel needs a peer that understands the token (a CWIST server with a datagram callback); against other peers that enable HTTP Datagrams, cwist_http3_client_send_datagram() fails instead of sending payloads the peer would misread.

Configure before the first connection.

Parameters
clientClient handle.
enabledNon-zero to enable (default: 0).
Returns
0 on success; -1 when the client has a live connection, the engine cannot be rebuilt, or WebTransport client support is not compiled in.

Enable or disable QUIC datagram support (RFC 9221).

When enabled, unreliable datagrams can be sent and received via cwist_http3_client_send_datagram() / recv_datagram(). Configure this before the first connection. Changing the setting on an active connection has no effect. This raw-only mode turns WebTransport off; use cwist_http3_client_enable_datagram_channel() to have both on one connection. Disabling datagrams also disables the datagram channel.

Parameters
clientClient handle.
enabledNon-zero to enable (default: 0).
