Enable or disable QUIC datagram support (RFC 9221).

When enabled, unreliable datagrams can be sent and received via cwist_http3_client_send_datagram() / recv_datagram(). Configure this before the first connection. Changing the setting on an active connection has no effect. Raw QUIC datagram mode and WebTransport mode are mutually exclusive on one client.

Parameters
clientClient handle.
enabledNon-zero to enable (default: 0).
