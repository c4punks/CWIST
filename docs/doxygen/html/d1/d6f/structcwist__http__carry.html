Detailed Description

Classic-pool pipelining carry: bytes a plain HTTP/1.1 connection had already read past a deferred request. The classic handler's read buffer lives on its stack and is gone once the handler returns, so dispatch copies the surplus onto the handle before the ack and the completion resubmits the connection with it (cwist_app_http_handler_resume).
