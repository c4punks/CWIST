void cwist_logger_log ( cwist_logger *  log,
cwist_log_level_t  level,
const char *  fmt,
  ... 
)

Logs a formatted message at the given level.

Write a log message.

Parameters
logLogger to log through; NULL is safely ignored.
levelLevel of the message; messages below the logger's level are suppressed.
fmtprintf-style format string.
Note
The message is written to stdout for levels below WARN and to stderr otherwise, with a timestamp, level tag, and logger name prefix, followed by a newline. The shared FILE streams are not locked across the prefix and the message, so lines from concurrent threads may interleave. In the sync fallback each line is still one fwrite(3) call (line-at-a-time write granularity), but stdio block-buffers the bytes, so lines are delivered in batches rather than per line; a TTY destination stays line-buffered. Call cwist_log_async_start() for immediate per-line delivery.
