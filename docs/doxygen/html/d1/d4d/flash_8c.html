Read and remove a flash entry.

Get a flash message and consume it (one-time read).

Destructive lookup: on success the entry's bucket is unlinked and freed, and ownership of the value string is transferred to the caller, who must release it with cwist_free().

Parameters
reqRequest whose flash map is read.
keyEntry key to look up.
Returns
Newly owned copy pointer to the value (caller frees), or NULL if req/key are NULL, the flash map is empty, or the key is missing.

◆ cwist_flash_pop_all_json()

char * cwist_flash_pop_all_json ( cwist_http_request *  req)

Serialize all flash entries to a JSON object and clear the map.

Serialize all flash messages to a JSON object string. Caller must free the returned string.

Builds a JSON object string {"key":"value",...} with '"' and '\' escaped in keys and values, then frees every flash entry and empties the map.

Parameters
reqRequest whose flash map is serialized.
Returns
Newly allocated NUL-terminated JSON string the caller must free with cwist_free(), or NULL if there are no entries or if a buffer allocation fails (in which case the flash map is left unchanged).
