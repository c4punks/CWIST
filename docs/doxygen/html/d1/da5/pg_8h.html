cwist_pg_t * cwist_pg_connect ( const char *  conninfo)

Connect to a PostgreSQL database using a connection string or URI.

Parameters
conninfoConnection string (e.g. "host=localhost dbname=test user=postgres") or URI (e.g. "postgresql://user:pass@host:port/dbname"). Connection and query operations have 5-second and 30-second deadlines respectively. A transport failure closes the connection.
Returns
Opaque connection handle, or NULL on allocation/connection failure.
