Detailed Description

Minimal STUN/ICE (RFC 5389 / RFC 8445) for the ICE-lite agent.

Implements just enough of STUN message parsing, validation, and construction to run an ICE-lite endpoint: binding request/response handling, MESSAGE-INTEGRITY (HMAC-SHA1) and FINGERPRINT (CRC-32) generation and checking, XOR-MAPPED-ADDRESS extraction, and random ICE credential generation. No retransmission or state machine logic lives here; callers in webrtc.c drive timing and nomination.

Build an unsigned ICE-controlling STUN binding request.

Build an unsigned Binding request (USERNAME, USE-CANDIDATE, ...).

The request carries USERNAME (only if username is non-empty), ICE-CONTROLLING, USE-CANDIDATE, and PRIORITY attributes. MESSAGE-INTEGRITY and FINGERPRINT are intentionally not added here; the MI key (the peer's password) is only known at send time, so the caller signs the built request with cwist_ice_stun_sign_request().

Parameters
outDestination buffer.
capCapacity of out in bytes.
txid12-byte transaction ID to copy into the header.
username"remoteufrag:localufrag" string for the USERNAME attribute; skipped when empty.
Returns
Total request length in bytes, or -1 if cap is too small.

Extract the sender's ufrag from the USERNAME attribute of a STUN message.

Extract the sender's ufrag from USERNAME ("recipient:sender", RFC 8445 section 7.2.2) – the peer's SDP ice-ufrag.

A Binding request's USERNAME is "<recipient ufrag>:<sender ufrag>" (RFC 8445 section 7.2.2), so for a request we received this returns the part after the first ':' – the remote peer's ufrag, as it appears in the peer's SDP.

Parameters
bufDatagram bytes.
lenNumber of bytes at buf.
outOutput buffer for the NUL-terminated ufrag.
capCapacity of out; output is truncated to cap - 1 characters.
Return values
0Ufrag extracted (possibly truncated).
-1Not a STUN message, or no USERNAME attribute present.

Validate a received STUN binding response.

Validate a response: cookie, txid match, MI with pwd, return mapped address.

Checks, in order: well-formed STUN message of type BINDING-RESPONSE, transaction ID match against txid, MESSAGE-INTEGRITY HMAC with pwd (via cwist_ice_stun_validate_request()), and presence of a MESSAGE-INTEGRITY attribute. If mapped is non-NULL, an IPv4 XOR-MAPPED-ADDRESS must also be present and is decoded into it.

Parameters
bufDatagram bytes.
lenNumber of bytes at buf.
txidTransaction ID the response must carry (the one we sent).
pwdLocal password used as the MI HMAC key.
mappedOptional output for the decoded mapped address.
Return values
1Valid response.
0Any check failed or the message is malformed.
