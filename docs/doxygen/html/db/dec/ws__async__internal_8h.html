Take ownership of a connected, upgraded fd and drive it reactively.

Registers a one-shot read slot with the reactor and returns. From then on the reactor drains the socket without blocking and delivers each complete message through on_message. The HTTP layer must not touch the fd after a successful attach (it returns CWIST_ASYNC_DETACH).

Parameters
fdConnected, upgraded client socket (set non-blocking here).
reactorOwning reactor.
on_messagePer-message callback.
user_dataOpaque pointer forwarded to the callback.
initialBytes already read past the upgrade request (conn->rbuf); fed through the frame parser before the first reactor wait.
initial_lenNumber of valid bytes at initial (0 when none).
Returns
true when the fd was handed to the reactor path, false on failure (fd is closed and all state freed before returning).

Attach variant that reports the connection handle and teardown.

Identical to cwist_websocket_async_attach() plus an optional on_close hook invoked exactly once on the reactor thread at final teardown (before the connection state is freed), and a return value exposing the handle to the caller.

Returns
Connection handle on success, NULL on failure (fd closed and all state freed before returning).

Attach variant that reports the connection handle and teardown.

Sets the fd non-blocking, feeds any bytes already read past the upgrade request through the parser (delivery can happen inline here, including a close from the on_message callback), arms the one-shot read slot, and joins the reactor's idle sweep. On any failure the fd is closed and all state is freed; on_close does not fire because the attach itself failed.

Parameters
fdUpgraded socket fd (owned by the new connection on success).
reactorReactor to register the fd with.
on_messageCallback invoked per complete message; takes ownership of the delivered frame. Must not be NULL.
on_closeOptional callback invoked exactly once during teardown.
user_dataOpaque pointer passed back to both callbacks.
initialBytes already read past the upgrade request; may be NULL.
initial_lenNumber of bytes in initial.
Returns
The new async connection, or NULL on invalid arguments or failure (fd is closed in the latter case).

Initiate the WebSocket close handshake with a CLOSE frame carrying a status code.

Close with a specific status code (e.g. graphql-ws 4400-4429 range) on the wire, mirroring cwist_websocket_async_close() teardown semantics.

The 2-byte big-endian status code is echoed to the peer. Idempotent: calling again on a connection already closing is a no-op. The connection is torn down once the CLOSE frame has drained or, on queueing failure, via a deferred termination.

Parameters
wsAsync connection to close. Safe to call with NULL.
codeRFC 6455 close status code (big-endian on the wire).
