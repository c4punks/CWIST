void cwist_error_dispose ( cwist_error_t *  err)

Release resources owned by an error value.

Release resources owned by an error value. Currently only CWIST_ERR_JSON owns memory (the cJSON payload); all other variants are no-ops. Safe on success values and on NULL.

Currently only CWIST_ERR_JSON owns memory (the cJSON payload); all other variants are no-ops. Safe on success values and on NULL. The released cJSON pointer is reset to NULL, but the rest of the error value is left as-is.

Parameters
errError object to release (may be NULL).
