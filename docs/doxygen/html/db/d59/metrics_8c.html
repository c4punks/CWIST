Observe a sample for a metric: accumulate sum and bump the count.

Observe a value into a histogram-like metric.

The value is stored with fixed-point scaling (roundl(value * 1000)), added to both the raw accumulated value and the sum, while the observation count is incremented by one. Lock-free relaxed atomic update; safe to call from any thread.

Parameters
regRegistry holding the metric; NULL is a no-op.
idMetric identifier; out-of-range ids are ignored.

Return the process-wide singleton metrics registry.

Obtain the global registry, creating it on first call.

Render the full registry in Prometheus text exposition format.

Render all metrics in Prometheus text exposition format.

Before rendering, synchronizes the HTTP_CONTINUATION_SHED metric from the live net/http shed counter into the registry (cast away const for that store). The output buffer grows by doubling and is heap-allocated; the caller owns it.

void cwist_metrics_serve_http ( cwist_http_response *  res)

HTTP handler that serves the metrics registry as Prometheus text.

Convenience helper: populate an HTTP response with /metrics body.

On success sets the response status to 200 OK with the exposition text as body and a Prometheus text Content-Type header. On render failure sets 500 INTERNAL_ERROR with a "metrics render failed" body.

Parameters
resResponse to fill; NULL is a no-op. The body sstring is assigned via cwist_sstring_assign.
