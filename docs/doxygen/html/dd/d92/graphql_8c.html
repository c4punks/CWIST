cwist_error_t cwist_graphql_execute ( cwist_graphql_schema_t *  schema,
const char *  request_json,
cwist_sstring **  out_json 
)

Execute a GraphQL query or mutation from a JSON request body.

The request must be a JSON object with a string "query" member and an optional "variables" object. On success *out_json receives a compact JSON response of the form {"data": {...}} with an "errors" array added when resolution produced errors. Ownership of *out_json transfers to the caller.

Parameters
schemaSchema providing the query/mutation fields.
request_jsonJSON-encoded GraphQL request text.
out_jsonReceives the response body string on success.
Returns
0 on success, non-zero on invalid arguments or internal failure.

Extract the root field name and parsed arguments of a subscription operation.

Used by the experimental WS subscription layer (cwist/net/graphql/graphql_ws.h); not part of the query/mutation execute path. Only the first root field is reported, matching the single-stream model of the graphql-ws broker.

Parameters

variablesOptional cJSON object of variable values.

Return values
trueThe subscription field and arguments were extracted.
falseInvalid arguments or malformed subscription query.

HTTP handler serving GraphQL requests over POST.

Executes the request body via cwist_graphql_execute() and writes the JSON response. Non-POST requests or execution failures yield a 400 status with an error body. The Content-Type header is always set to application/json.

Parameters
schemaSchema used to resolve the request.
reqIncoming HTTP request (must use POST).
resResponse object receiving status, body, and headers.
