int cwist_http_async_conn_fill ( cwist_http_async_conn_t *  conn)

Drain the socket into the connection stash. Stops at EAGAIN, and also after a short read: poll is level-triggered, so if bytes remain after a short recv the one-shot re-arm fires again immediately.
