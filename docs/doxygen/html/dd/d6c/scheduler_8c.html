Detailed Description

Background job scheduler with delayed execution.

The scheduler is built on top of cwist_io_queue. Worker threads run the queue's event loop, and a dedicated timer thread maintains a min-heap of delayed jobs. When a delayed deadline arrives, the timer thread submits the job to the io queue so a worker can execute it.

Cancel all delayed jobs that have not yet fired.

Detaches the delayed-job heap under s->delayed_mtx and invokes drop_cb(arg) for each cancelled job outside the lock so caller destructors cannot deadlock on scheduler re-entry. Jobs already submitted to the io queue by the timer thread before this call are not affected.

Parameters
sScheduler whose pending jobs are to be cancelled.
drop_cbDestructor called once per cancelled job's arg; may be NULL.
Returns
Number of jobs cancelled.

Schedule a job to run after a delay.

Schedule a job to run after a relative delay.

With a zero delay the job is submitted immediately as with cwist_scheduler_submit(). Otherwise it is pushed onto the delayed-job min-heap and the timer thread runs it once the deadline passes.
