Set or replace a cookie in the client's jar. A cookie with the same name gets its value replaced (and path, if path is given); otherwise a new cookie is prepended to the jar. Strings are copied.

Set a persistent cookie in the client's cookie jar.

Parameters
clientClient owning the jar; NULL is a no-op.
nameCookie name; must not be NULL.
valueCookie value; NULL clears the stored value.
pathCookie path; NULL leaves the path unchanged for existing cookies or stores no path for new ones.
