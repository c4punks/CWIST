Encrypt an SQLite database blob.

Generates a random DEK and IV pair, encrypts sqlite_bytes with the DEK, wraps the DEK under the KEK, and returns the complete sealed blob.

Parameters
ctxKey context (kek must be filled).
sqlite_bytesRaw SQLite database bytes (from sqlite3_serialize or a file read).
sqlite_lenLength of sqlite_bytes.
[out]out_lenLength of the returned blob.
Returns
Heap-allocated sealed blob, or NULL on error. Caller must free() the returned pointer.
