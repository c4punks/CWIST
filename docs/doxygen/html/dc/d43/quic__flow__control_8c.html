void quic_flow_control_adjust_windows ( quic_conn_fc_t *  fc,
quic_stream_fc_t *  sfc 
)

Grow flow control windows when the network quality is degraded.

Only acts when the connection quality is at least QUIC_NET_QUALITY_HIGH_RTT. Each window that is below its configured maximum is doubled, capped at that maximum. No-op if fc is NULL or quality is better than QUIC_NET_QUALITY_HIGH_RTT; sfc may be NULL, in which case only the connection window is adjusted.

Parameters
fcConnection flow control state.
sfcStream flow control state to adjust, or NULL.

quic_net_quality_t quic_flow_control_evaluate_quality ( quic_conn_fc_t *  fc)

Recompute the network quality class from the smoothed RTT.

Classifies by srtt thresholds: <= 50 ms excellent, <= 150 ms normal, <= 500 ms high RTT, above that poor. The result is stored in fc->quality and returned. Returns QUIC_NET_QUALITY_NORMAL if fc is NULL or no RTT sample has been recorded yet.

Parameters
fcConnection flow control state.
Returns
The (updated) quality classification.

Write a MAX_DATA frame if the connection limit should be raised.

Unless force is set, a frame is produced only when at least half of the connection window has been consumed (see should_update()). The new maximum is consumed + window, never lower than the current maximum, and is stored back in fc->max_data on success. On entry *written is cleared to 0 when written is non-NULL.

Parameters
fcConnection flow control state.
bufOutput buffer for the encoded frame.
buf_lenCapacity of buf in bytes.
writtenReceives the encoded frame length in bytes.
forceEmit the frame even if the update threshold is not met.
Return values
1Frame written; *written holds its length.
0No update needed; nothing written.
-1Invalid argument or buf too small; nothing written.

◆ quic_flow_control_update_rtt()

void quic_flow_control_update_rtt ( quic_conn_fc_t *  fc,
uint64_t  rtt_sample_us 
)

Feed an RTT sample into the smoothed RTT estimator and re-evaluate quality.

Uses RFC 6298-style smoothing: rttvar is updated with weight 1/4 and srtt with weight 1/8; the first sample initializes both. Tracked state is confined to fc and is not thread-safe across concurrent calls on the same connection. No-op if fc is NULL or rtt_sample_us is zero.

Parameters
fcConnection flow control state.
rtt_sample_usLatest RTT sample in microseconds.
