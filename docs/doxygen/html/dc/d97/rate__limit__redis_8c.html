◆ cwist_mw_rate_limit_ip_redis()

cwist_middleware_func cwist_mw_rate_limit_ip_redis ( const cwist_rate_limit_redis_cfg_t *  cfg)

Shared per-IP 60-second window using one atomic Redis Lua command.

Uses the socket peer, never forwarded headers. A rejected request returns 429 with Retry-After: 60. Backend errors and missing peer addresses follow fail_closed. The first backend failure per configuration in each process writes its error code and policy to stderr (no keys or credentials). No local fallback counter is used. Requests do not extend TTL. Use a dedicated pool on DB 0, with the default user and no AUTH.

Create the pool separately in every serving process after fork. Pool creation and DNS are blocking; timeout_ms bounds request-time pool wait and I/O. Use cwist_app_listen_ex() with one worker or CWIST_WORKERS=1, so the application listener does not fork the initialized pool. Do not destroy the pool while calls may still run. Eight distinct immutable configurations are supported per process; equal configurations reuse a slot.

Returns
Middleware, or NULL for invalid configuration or exhausted slots.
