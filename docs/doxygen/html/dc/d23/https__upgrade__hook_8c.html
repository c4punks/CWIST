__attribute__ ( (weak)  )

Optional hook called after a successful TLS upgrade of a connection.

Weak default implementation that keeps cwist ownership of the connection. Applications that need to take ownership of a TLS-upgraded connection (e.g. reverse-session hijacking) provide their own strong definition of this symbol, which overrides this stub at static link time.

Parameters
connThe upgraded HTTPS connection.
reqThe HTTP request that triggered the upgrade.
resThe HTTP response to be sent before detaching.
Returns
true to detach the fd/ssl from cwist so they are not closed after the response is sent; false to keep cwist ownership (the default).
