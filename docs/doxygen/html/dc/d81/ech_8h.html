Enable Encrypted Client Hello (ECH) for the application.

Enable Encrypted Client Hello (ECH) for the application.

When built against OpenSSL 3.2 or newer with ECH support (SSL_OP_ENABLE_ECH defined), this sets the ECH option on the application's SSL context. On older OpenSSL versions this is a no-op that still succeeds. The ech_key and ech_dir arguments are currently accepted but not used.

Parameters
appApplication whose SSL context is configured. Must not be NULL.
ech_keyUnused placeholder for a future ECH key configuration.
ech_dirUnused placeholder for a future ECH directory source.
Return values
CWIST_ERROR_INVALID_PARAMapp is NULL.
0Success; ECH was enabled or is unsupported on this build.
