typedef bool(* cwist_app_fallback_match_fn) (cwist_app *app, cwist_http_request *req)

In-tree fallback dispatch (used by the reverse proxy). When installed, requests that match no route are offered to match before assets, static directories and the 404 handler; on a true return handler runs through the app's middleware chain. Install once before serving; pass NULLs to remove. Not a public API: the hook is process-global.
