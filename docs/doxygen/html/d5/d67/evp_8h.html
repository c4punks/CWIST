Detailed Description

mbedTLS TLS backend: EVP subset (HMAC digest tags, AES-256-CBC).

Part of the CWIST TLS backend seam; see shim/openssl/ssl.h for the design. Only what CWIST call sites use: EVP_sha256() as an HMAC digest selector and the AES-256-CBC cipher context API used by db_crypt and the (dormant under mbedTLS) session-ticket key callback.
