Detailed Description

Locale-independent day and month names for HTTP and log dates.

strftime("%a") and "%b" follow LC_TIME, so a program that calls setlocale(LC_ALL, "") would emit localized names. HTTP dates (RFC 9110 section 5.6.7) and Common Log Format need the English ones.
