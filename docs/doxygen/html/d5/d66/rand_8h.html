Detailed Description

mbedTLS TLS backend: RAND_bytes over mbedTLS CTR-DRBG.

Part of the CWIST TLS backend seam; see shim/openssl/ssl.h for the design. The DRBG is seeded lazily from the system entropy source and re-seeded after fork(), so CWIST's pre-fork worker model never shares DRBG state between worker processes.
