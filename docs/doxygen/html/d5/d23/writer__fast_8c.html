Attempt a single non-blocking speculative write of a buffer to a socket.

Speculative non-blocking direct sender.

Performs one best-effort send() with MSG_DONTWAIT (plus MSG_NOSIGNAL when available). Never blocks: if the socket buffer is full, the write is left pending for the caller's blocking drain path.

Parameters
fdConnected socket descriptor.
bufData to send; must not be NULL unless len is 0.
lenNumber of bytes to send.
sent_outOptional output; receives the number of bytes accepted by the socket (0 on EAGAIN or when nothing was sent).
Return values
CWIST_WRITE_DONEThe whole buffer was sent.
CWIST_WRITE_PENDINGPartial progress or the socket would block.
CWIST_WRITE_ERRA hard send error occurred.

Attempt a single non-blocking speculative sendmsg over an iovec array.

Speculative scatter/gather sendmsg without blocking poll().

Like cwist_http_send_speculative(), but sends a scatter/gather buffer. Under CWIST_WASI_SOCKETS (no sendmsg(2) in wasi:sockets 0.2) the iovecs are coalesced into one heap allocation (owned and freed here) and sent with a single send(); the blocking drain in cwist_http_sendmsg_all() re-drives whatever remains.

Parameters
fdConnected socket descriptor.
iovArray of iovec entries; must not be NULL unless iovcnt <= 0.
iovcntNumber of entries in iov.
flagsExtra send flags ORed into MSG_DONTWAIT/MSG_NOSIGNAL.
total_sentOptional output; receives total bytes accepted by the socket (0 on EAGAIN or when nothing was sent).
Return values
CWIST_WRITE_DONEThe entire payload was sent.
CWIST_WRITE_PENDINGPartial progress or the socket would block.
CWIST_WRITE_ERRAllocation or hard send error occurred.

Select the less-loaded of two randomly sampled workers (power-of-two choices).

Select worker using Power of Two Random Choices (P2C).

Draws two distinct worker indices using a thread-local xorshift32 PRNG, reads their current loads with a relaxed atomic load, and returns the index of the worker with the smaller load. Thread-safe: the PRNG seed is _Thread_local and the load array is only read.

Parameters
worker_loadsArray of per-worker load counters (atomic uint32_t).
num_workersNumber of workers in the array.
Returns
Index of the selected worker; 0 if worker_loads is NULL or num_workers <= 1.
