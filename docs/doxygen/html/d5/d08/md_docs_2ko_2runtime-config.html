런타임 설정

프레임워크가 읽는 CWIST_* 환경 변수를 모두 여기에 적습니다. scripts/ci/check_env_knobs.py(make env-check, CI에서 실행)는 src/가 이 문서에 없는 변수를 읽거나, 이 문서에 있는 변수를 src/가 더 이상 읽지 않으면 실패합니다. 그래서 표가 빠짐없이 유지됩니다.

대부분의 변수는 처음 쓸 때 한 번 읽고 저장해 둡니다. 서비스 중에 바꾸지 말고 프로세스 시작 전(또는 cwist_app_listen() 전)에 설정하세요. 비어 있거나 형식이 잘못된 값은, 행에 따로 적지 않은 한 기본값으로 돌아갑니다.

상태

변수마다 상태가 하나씩 있습니다. 상태는 v4가 그 변수에 대해 무엇을 약속하는지 나타냅니다.

상태 v4 시리즈 동안의 약속
supported 이름과 의미를 유지합니다. v5 전에는 제거하거나 다른 뜻으로 바꾸지 않으며, v4 태그 이후 사라지면 CI 검사가 실패합니다.
tuning 이름은 유지하지만, 엔진이 바뀌면서 효과와 기본값은 마이너 릴리스 사이에 바뀔 수 있습니다. 값에 의존하기 전에 측정하세요.
diagnostic 디버깅 전용입니다. 출력 형식과 동작은 안정적이지 않으며 어느 릴리스에서든 바뀌거나 없어질 수 있습니다.

프로세스와 서버 모드

변수 상태 값 기본값 효과
CWIST_WORKERS supported 정수 1 이벤트 루프 전에 fork하는 워커 프로세스 수.
CWIST_C1M_MODE supported 0 또는 false면 끔 1 1은 CWIST reactor(C1M)로 서비스하고, 0은 classic 스레드 풀을 고릅니다.
CWIST_PROFILE supported default, performance, lowmem, lowlat default 환경에 설정되지 않은 다른 변수를 채우는 프리셋입니다(명시한 값이 우선). default: CWIST_C1M_MODE=1, CWIST_REACTOR_DRAIN_CHUNK=8. performance: 여기에 CWIST_MALLOC_ARENA_MAX=1, CWIST_HTTP_BATCH=64 추가. lowmem: CWIST_C1M_MODE=1, CWIST_MALLOC_ARENA_MAX=1, CWIST_WORKERS=2. lowlat: CWIST_C1M_MODE=0. 모르는 값이면 경고하고 default를 씁니다.
CWIST_DRAIN_TIMEOUT supported 초, 0–3600 5 종료 시 앱을 해제하기 전에 처리 중인 요청을 기다리는 시간. 범위 밖 값은 stderr에 알리고 무시합니다.
CWIST_REUSEPORT supported 0 또는 false면 끔 켜짐 TCP와 UDP(HTTP/3) 리슨 소켓에 SO_REUSEPORT를 설정해 두 번째 프로세스가 같은 포트를 바인드할 수 있게 합니다(무중단 재시작, 무중단 재시작 참조). 끄면 포트 충돌 시 bind()가 실패하지만, 워커 프로세스는 fork 후 포트를 다시 바인드하므로 CWIST_WORKERS=1이 필요합니다.
CWIST_FD_LIMIT_TARGET supported 0보다 큰 정수 1050000 서버가 시작할 때 스스로 올리는 열린 파일 soft limit(hard limit까지). C1M 파일 한도 참고.
CWIST_MALLOC_ARENA_MAX tuning 0 이상 정수 설정 안 함(glibc 기본값) glibc 전용: mallopt(M_ARENA_MAX). 1은 할당기 동시성을 조금 내주고 RSS를 크게 줄입니다.
CWIST_MALLOC_TRIM_IDLE_SEC tuning 초, 0–86400 30 glibc 전용(그 외 libc에서는 동작 없음): 이벤트 없이 유휴 상태가 누적된 시간이 이 값에 도달하면 리액터가 이벤트 없는 wake에서 malloc_trim(0)을 호출해 glibc 아레나 상단의 여유 메모리를 OS에 반환합니다. 유휴 wake에서만 동작해 핫 패스 비용은 없습니다. 로드 라운드 후 워커당 중간값 약 1.2 MiB 절감. 0이면 끕니다.

변수 상태 값 기본값 효과
CWIST_HTTP_KEEP_ALIVE_TIMEOUT supported 초, 0보다 큼 15 keep-alive 연결을 닫기 전 유휴 시간.
CWIST_ASYNC_STASH_IDLE_SEC tuning 초, 0 이상 10 C1M async HTTP: keep-alive 연결의 큰 rbuf/obuf stash를 re-arm 시 4 KiB 바닥으로 축소하기 전에 용량이 필요 없었던 시간. 바쁜 연결은 용량을 유지해 요청마다 일어나는 축소→재확장 realloc을 없애고, 유휴 연결은 이 시간만큼 늦게 바닥에 수렴합니다. 0이면 기존처럼 즉시 축소합니다.
CWIST_HTTP_BATCH tuning 1–1024 16 이벤트 루프 한 턴에 디스패치하는 파이프라인 요청 수. 나머지는 다음 턴에 이어집니다.
CWIST_HTTP_YIELD_BATCH tuning 1–1024 CWIST_HTTP_BATCH 연결이 reactor 큐로 양보하기 전에 한 배치 안에서 처리하는 요청 수.
CWIST_USE_TCP_CORK tuning 0보다 큰 정수 꺼짐 Linux, 평문 HTTP/1.1: 소켓을 cork해서 헤더, 본문, 파일 바이트를 꽉 찬 세그먼트로 보냅니다.
CWIST_TCP_CORK_BURST tuning 바이트, 16384 이상 262144 CWIST_USE_TCP_CORK를 켰을 때 파일 본문을 한꺼번에가 아니라 이 바이트마다 내보냅니다.

Reactor

변수 상태 값 기본값 효과
CWIST_REACTOR_BACKEND tuning epoll io_uring Linux: A/B 측정용으로 epoll 백엔드를 강제합니다.
CWIST_RX_URING tuning 0이면 끔 켜짐 POLL + recv 대신 IORING_OP_RECV로 받습니다.
CWIST_ACCEPT_URING tuning 0이면 끔 켜짐 one-shot POLL + accept4 반복 대신 multishot IORING_OP_ACCEPT 하나로 새 연결을 받습니다. multishot accept를 지원하지 않는 커널은 조용히 poll 경로로 돌아갑니다.
CWIST_RX_EPOLL tuning 0이면 끔 켜짐 epoll reactor(io_uring ring이 없거나 CWIST_REACTOR_BACKEND=epoll)에서 keep-alive 연결을 edge-triggered로 등록해 둔 채 reactor가 직접 받습니다. 요청마다 epoll_ctl로 one-shot poll을 다시 거는 대신입니다.
CWIST_REACTOR_DRAIN_CHUNK tuning 0 이상 정수 8 (CWIST_PROFILE이 설정, 없으면 64) 게시된 작업을 비우는 사이에 처리하는 연결 콜백 수. 모든 reactor 백엔드(io_uring, epoll, kqueue)에 적용됩니다. 0이면 묶음 중간의 비우기를 끕니다(기존 동작). 협력적 큐잉 참고.
CWIST_REACTOR_ROUND_BUDGET_US tuning 마이크로초, 0 이상 2000 reactor 라운드가 이 시간을 넘기면, 대기 중인 re-arm을 라운드 끝이 아니라 콜백 64개마다 커널에 넘깁니다. 라운드는 끝까지 실행됩니다. 0이면 한도를 끕니다.
CWIST_REACTOR_CQ_GRACE_NS tuning 나노초, 0 이상 20000 커널에서 잠들기 전에 completion ring을 확인하며 도는 시간. 0이면 돌지 않습니다.
