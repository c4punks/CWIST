◆ http_auto_promote

bool cwist_proxy_config::http_auto_promote

Let HTTP/1.1 (and HTTP/2) clients move to the newest enabled protocol: responses advertise Alt-Svc: h3=":<port>" when h3 is enabled, and TLS listeners offer h2 through ALPN when h2 is enabled. When false, proxied responses carry Alt-Svc: clear, so only clients that already target HTTP/3 use it. Cleartext h2c Upgrade is not offered (RFC 9113 deprecates it).

◆ tls_auto_promote

bool cwist_proxy_config::tls_auto_promote

Promote TLS to hybrid post-quantum key exchange (X25519MLKEM768, TLS 1.3) on both sides: front listeners (TCP and QUIC) prefer it, and every https:// upstream must negotiate it or the request fails with 502. When false, an https:// upstream keeps the client's level instead: the same minimum TLS version, and post-quantum key exchange only when the client negotiated it. http:// targets always terminate TLS here.
