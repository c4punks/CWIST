Append an out-of-band swapped element to the response body.

Append an out-of-band element to a fragment response.

The element must have an "id" attribute. When the client requested a full page the element is dropped (a full page already contains the region) and success is reported. Otherwise an hx-swap-oob="true" attribute is added if missing and the element is rendered and appended to the body. Takes ownership of el in all cases.

Parameters
reqRequest used to decide whether an OOB update applies.
resResponse whose body the rendered element is appended to.
elElement to append; consumed regardless of the result.
Returns
0 on success (including the dropped full-page case), -1 if the response cannot hold HTML, the element has no id, or rendering or appending fails.

Redirect an HTML request to location, using htmx headers when applicable.

Redirect in a way both plain navigation and fragment clients follow.

For htmx requests (HX-Request: true) the status stays 200 and the target is sent via the HX-Redirect header; otherwise a 303 See Other response with a Location header is produced. Any previous Location and HX-Redirect headers are removed and the body is cleared.

Parameters
reqRequest used to decide between htmx and regular redirects.
resResponse to modify.
locationRedirect target; must be non-empty and free of control bytes.
Returns
0 on success, -1 if the response cannot hold HTML, the location is invalid, or header/body updates fail.

Set the response body from content, wrapping it in layout for full pages.

Answer with a fragment or a full page, depending on the request.

When the client requested a fragment, content is rendered alone; otherwise it is embedded into the layout component (or rendered as a full document when no layout is given). Takes ownership of content in all cases. On success a Vary header for fragment-negotiation is appended.

Parameters
reqRequest used to decide between fragment and full-page rendering.
resResponse whose body is replaced.
contentElement tree for the page content; consumed regardless of the result.
layoutOptional layout component that wraps content; may be NULL.
layout_propsProps passed to the layout component.
Returns
0 on success, -1 if the response cannot hold HTML, content is NULL, or rendering fails.
