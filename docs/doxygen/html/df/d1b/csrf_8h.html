cwist_middleware_func cwist_mw_csrf ( cwist_app *  app)

CSRF middleware factory.

On safe requests (GET/HEAD/OPTIONS) a csrf_token cookie is issued if missing. On unsafe requests the X-CSRF-Token header, _csrf form field, or URL-encoded _csrf / csrf_token form field must match the cookie value. Query-string tokens are not accepted because URLs leak easily.
