typedef struct cwist_compress_backend cwist_compress_backend

Compression backend vtable.

Implementations provide init/compress/finish/cleanup lifecycle hooks. The middleware uses this interface so backends can be swapped or extended (e.g., Brotli, zstd) without changing middleware logic.
