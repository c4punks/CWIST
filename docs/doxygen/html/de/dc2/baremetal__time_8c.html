Detailed Description

clock_gettime(), nanosleep() and timegm() for CWIST_BAREMETAL.

newlib declares these once -D_POSIX_TIMERS / -D_POSIX_MONOTONIC_CLOCK are set (see BAREMETAL_CFLAGS) but implements none of them:

  • clock_gettime(CLOCK_MONOTONIC) comes from cwist_port_monotonic_ns(); CLOCK_REALTIME from gettimeofday(), i.e. the firmware's RTC if any.
  • nanosleep() busy-waits on the monotonic clock.
  • timegm() is Howard Hinnant's days_from_civil.

Kept apart from baremetal.c so tests/test_baremetal_port.c can build it on the host with the three names renamed (-Dclock_gettime=... etc.).
