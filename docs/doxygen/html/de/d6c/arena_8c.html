Detailed Description

Request-scoped arena allocator built on libttak arena generations.

Performance notes:

  • Generation buffers are recycled through target-specific free lists, so steady-state requests avoid repeated allocator and epoch-GC work.
  • Hosted builds keep their arena environment in thread-local storage and clean it with a pthread key destructor; non-hosted builds use a bounded single-thread cache of arena structs and generation buffers.
