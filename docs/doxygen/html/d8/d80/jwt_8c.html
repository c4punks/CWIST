const char *  kid,

Sign a JWT token with ES256 (ECDSA over P-256 with SHA-256).

Behaves like cwist_jwt_sign() except the signature is asymmetric: the header declares "alg":"ES256" and the signature is the 64-byte raw R||S form required by JOSE (RFC 7518 section 3.4).

Parameters
payload_jsonJSON string for the payload (see cwist_jwt_sign()).
pem_private_keyPEM-encoded EC private key (SEC 1 or PKCS#8), null-terminated. The key's curve must be P-256.
kidOptional key id written into the JWT header, or NULL.
exp_secondsSeconds until expiry (see cwist_jwt_sign()).
Returns
Heap-allocated null-terminated JWT string, or NULL on error. Caller must free with cwist_free().

◆ cwist_jwt_verify_es256()

cwist_jwt_claims * cwist_jwt_verify_es256 ( const char *  token,
const char *  pem_key 
)

Verify an ES256-signed JWT token and return the decoded claims.

The header must declare exactly "alg":"ES256" (a token signed with any other algorithm is rejected, which also closes the HS256/ES256 confusion class of RFC 8725 section 2.1) and the signature must verify against the public half of pem_key. The "exp"/"nbf" checks match cwist_jwt_verify().

Parameters
tokenNull-terminated JWT string ("header.payload.sig").
pem_keyPEM-encoded EC P-256 public key (or private key; the public half is used), null-terminated.
Returns
Pointer to a cwist_jwt_claims object on success, NULL on failure. Caller must free with cwist_jwt_claims_destroy().
