Detailed Description

Tiny ORM client over a framed Unix socket stream.

This implementation never includes sqlite3.h. All communication with the SQL backend is serialised through a socket produced by cwist_db_transfer_sqlite_to_socket().

Destroy an ORM session and close its underlying socket.

Wrap a connected socket descriptor in an ORM session.

Create an ORM session from an existing SQL socket.

Takes ownership of socket_fd: the descriptor is closed by cwist_orm_close_socket(). The session inherits the current global immediate-commit default and defaults to the SQLite dialect.

Parameters
socket_fdConnected socket descriptor (must be >= 0).
Returns
New ORM handle, or NULL on invalid descriptor or allocation failure.
