Detailed Description

Tiny ORM client over a framed Unix socket stream.

This implementation never includes sqlite3.h. All communication with the SQL backend is serialised through a socket produced by cwist_db_transfer_sqlite_to_socket().

Select a single integer cell exactly as an int64_t.

Same query as cwist_orm_select_one_llong(), but the value is read from the integer digits the worker sent instead of through a cJSON number (a double), so integers above 2^53 (snowflake-style IDs) keep every digit. The cell must be a JSON integer, or a JSON string holding canonical integer text (an optional '-' and digits, no leading zeros).

columnColumn name.
