◆ cwist_reg_ptr_sized()

void cwist_reg_ptr_sized ( cwist_gc_t *  gc,
void *  ptr,
size_t  size 
)

Register a pointer and its approximate size with the epoch GC.

Register a pointer and its size for better accounting.

The pointer must be releasable with cwist_free() (i.e. come from CWIST's allocator: cwist_alloc() and family). The wrapper records the pointer in its own registry so that cwist_gc_shutdown() can detach it from libttak's mem_tree and release it with cwist_free(); libttak's destroy-time pass frees with ttak_mem_free(), which aborts on headerless cwist_alloc blocks. Pointers allocated directly from libttak (ttak_mem_alloc_safe()) must NOT go through here; register them with the raw context instead — ttak_epoch_gc_register(cwist_gc_raw(gc), ptr, size) — so libttak's own teardown releases them.

Ownership: after registration the context owns the block and will free it at shutdown. An explicit cwist_free() first detaches it automatically; registering the same pointer with another context moves tracking there.

Parameters
gcGC context that tracks the pointer.
ptrPointer to retire through the epoch GC.
sizeOptional size hint associated with ptr.
