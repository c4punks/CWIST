Render an in-memory template string against a JSON context object.

Renders a template string with the given cJSON context.

Include paths in an in-memory template have no directory origin, so relative includes resolve against the process working directory. Use cwist_template_render_file() when file-relative includes are needed.

Parameters
template_strTemplate source to render.
contextJSON object supplying values for substitutions and control flow.
Returns
Heap-allocated rendered output, or NULL on failure.

Render a file, confining every nested {% include %} to include_root.

file_path itself is opened as given; the root applies to the files it includes, at any depth. Relative includes still resolve against the including file's directory, exactly as in cwist_template_render_file(). See cwist_template_render_rooted() for how the root is enforced.

cwist_sstring * cwist_template_render_rooted ( const char *  template_str,
const cJSON *  context,
const char *  include_root,
cwist_template_error_t *  error 
)

Render a string, confining every {% include %} to include_root.

Relative includes resolve against include_root (an in-memory string has no directory of its own). Each included file is canonicalized (symlinks and ".." resolved) and rejected with CWIST_TEMPLATE_ERROR_FORBIDDEN unless it lies inside the canonical include_root. The root does not change which file an include names; it only rejects files outside it.

Parameters
template_strTemplate source, as for cwist_template_render().
contextJSON rendering context; may be NULL.
include_rootExisting directory that includes must stay inside. A missing or NULL root fails with CWIST_TEMPLATE_ERROR_INVALID_ARGUMENT.
errorOptional output diagnostic; may be NULL.
Returns
Rendered string owned by the caller, or NULL on failure.
