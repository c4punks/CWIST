Connect to a NATS server and create a handle.

Connect to a NATS server.

Allocates a cwist_nats_t and connects to the given URL, or to the NATS default URL when url is NULL.

Parameters
[out]natsReceives the new handle on success; must not be NULL.
urlServer URL, or NULL for the default server.
Returns
cwist_error_t with err_i16 set to 0 on success, CWIST_ERROR_INVALID_PARAM if nats is NULL, CWIST_ERROR_NOMEM on allocation failure, or the natsStatus code on connection failure.

Publish a NUL-terminated string message to a subject.

Publish a string message.

A NULL data is published as an empty string. Flushes the connection after publishing so the message is written out before returning.

Parameters

subjectSubject to publish to; must not be NULL.
dataPayload string, or NULL to send an empty payload.

Subscribe to a NATS subject and register a message callback.

Subscribe to a subject.

Replaces any existing subscription on the handle: the previous subscription is destroyed before the new one is created. The callback is invoked from the NATS delivery thread via cwist_nats_adapter.

Parameters
natsHandle with an active connection; must not be NULL.
subjectSubject to subscribe to; must not be NULL.
cbCallback invoked for each incoming message; may be NULL.
ctxOpaque pointer passed back to cb.
Returns
cwist_error_t with err_i16 set to 0 on success, CWIST_ERROR_INVALID_PARAM on NULL arguments, or the natsStatus code on failure.
