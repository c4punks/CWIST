Detailed Description

mbedTLS TLS backend: error queue subset.

Part of the CWIST TLS backend seam; see shim/openssl/ssl.h for the design. The "error queue" is a single thread-local slot holding the last mbedTLS error code; ERR_error_string_n renders it with mbedtls_strerror().
