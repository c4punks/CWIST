Detailed Description

Tiny ORM over a SQL socket stream.

This header provides a socket-backed ORM interface. It intentionally never includes sqlite3.h; all communication with the SQL backend happens through a Unix domain socket obtained from cwist_db_transfer_sqlite_to_socket().

The default transaction mode is manual (immediate commit disabled). Call cwist_orm_immediate_commit(true) to make every write operation automatically commit.

Values in the cJSON data objects are escaped and table/column names are quoted before they reach the SQL text. Raw SQL arguments are not: sql in cwist_orm_exec() / cwist_orm_query(), every where_clause, and the columns list of cwist_orm_select() are inserted verbatim. Do not build those strings from untrusted input.

Storage class of a typed result cell.

The class comes from the SQLite value's storage class (sqlite3_column_type()), not from its text: a TEXT column holding canonical integer text is CWIST_ORM_TYPE_TEXT, and SQL NULL is CWIST_ORM_TYPE_NULL, distinct from an empty TEXT value.

◆ cwist_orm_immediate_commit()

void cwist_orm_immediate_commit ( bool  enable)

Toggle automatic commit mode.

When enabled, every cwist_orm_insert(), cwist_orm_update(), cwist_orm_delete(), and cwist_orm_exec() automatically appends a COMMIT statement so that the change is persisted immediately.

When disabled (the default), the caller is responsible for wrapping operations in explicit transactions via cwist_orm_commit() or cwist_orm_rollback().

Parameters
enabletrue to enable auto-commit, false to disable.

Toggle automatic commit mode.

Sessions opened afterwards inherit this value; existing sessions are not affected. When enabled, INSERT/UPDATE/DELETE statements executed through cwist_orm_exec() are followed by an automatic COMMIT.

Parameters
enabletrue to enable immediate commit, false to disable.

Execute a SELECT-style query and return column-typed rows.

Values are typed by each cell's SQLite storage class, not by its text, unlike cwist_orm_query() whose JSON values keep the legacy text-based typing (canonical integer text becomes a number there).
