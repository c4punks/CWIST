129/* --- HTTP/3 deferred responses ------------------------------------------
130 *
131 * lsquic runs every HTTP/3 connection of a server loop on one engine thread
132 * and is not thread-safe, so a completing producer never touches the stream.
133 * It enqueues the finished exchange on the loop's queue and pokes its wake
134 * fd; the engine thread drains the queue and resumes the stream. The stream
135 * is named by a refcounted token the engine thread detaches when the stream
136 * closes first, so a late completion is discarded instead of reaching freed
137 * stream state. Implemented in http3.c. */
