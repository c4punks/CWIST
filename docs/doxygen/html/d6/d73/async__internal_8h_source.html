123/* --- HTTP/3 deferred responses ------------------------------------------
124 *
125 * lsquic runs every HTTP/3 connection of a server loop on one engine thread
126 * and is not thread-safe, so a completing producer never touches the stream.
127 * It enqueues the finished exchange on the loop's queue and pokes its wake
128 * fd; the engine thread drains the queue and resumes the stream. The stream
129 * is named by a refcounted token the engine thread detaches when the stream
130 * closes first, so a late completion is discarded instead of reaching freed
131 * stream state. Implemented in http3.c. */
