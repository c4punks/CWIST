◆ cwist_realloc_shim()

void * cwist_realloc_shim ( void *  ptr,
size_t  size 
)

realloc() shim; see cwist_malloc_shim(). Tracking follows the incoming pointer (see the header doc comment for the exact rule) rather than unconditionally tracking every result, since a pointer's caller may have already disowned it (cwist_gc_scope_disown()) or allocated it before full-GC was ever enabled.

realloc() replacement. Tracking follows the incoming pointer: if ptr was tracked (shimmed-and-full-GC-was-on at allocation time), the old registration is removed and the new pointer is re-registered (a moved block must not leave a stale entry pointing at freed memory, and should stay reclaimable exactly as the original was). If ptr was untracked (allocated before full-GC was enabled, already disowned, or is NULL), the result is left untracked too - matching cwist_realloc()'s existing behavior of not opting a pointer into tracking on its own.
