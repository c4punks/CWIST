Initialize connection-level flow-control state.

Windows below the protocol defaults are raised to the defaults, and the maximum window is clamped to CWIST_HTTP2_MAX_WINDOW. Zeroes the whole state, then seeds receive/target/min/send windows with the initial connection window, and grants half a window of initial pacing tokens at 10x the initial window in bytes per second as a provisional pacing rate until RTT samples recalibrate it.

Parameters
flow_controlConnection flow-control state to initialize.
initial_connection_windowRequested initial connection window; values below CWIST_HTTP2_INITIAL_CONNECTION_WINDOW select the default.
max_connection_windowUpper bound for the dynamic window; raised to at least the initial window and capped at CWIST_HTTP2_MAX_WINDOW.

Emit a connection-level WINDOW_UPDATE when enough credit is due.

Does nothing until at least half the target window has been consumed (unless force), then retunes the target against the measured bandwidth-delay product and serializes a WINDOW_UPDATE for stream 0 into the caller's buffer. On success the receive window is credited with the increment (saturating at CWIST_HTTP2_MAX_WINDOW), the pending accumulator is cleared, and the update timestamp is advanced.

Parameters
flow_controlConnection flow-control state.
bufferDestination buffer for the serialized frame.
buffer_lenAvailable bytes in buffer (at least 13 required).
writtenSet to 0 when no frame is emitted, to 13 on success.
now_usCurrent time in microseconds; drives retuning.
forceEmit the update even when less than half the target window is pending.
Returns
1 when a WINDOW_UPDATE frame was written, 0 when no update is due or flow_control is NULL, -1 when the frame could not be serialized.

Compute how much of a send request may proceed right now.

Refills the pacing token bucket from the elapsed time since the last call, capping the refill at one target window's worth of tokens (and capping the elapsed computation so it stays inside uint64 regardless of idle time). The result is the smallest of the requested size, the connection send window, the stream send window, and the available pacing tokens.

Parameters

stream_flow_controlStream flow-control state holding the stream send window.
requestedNumber of bytes the caller wants to send.
now_usCurrent time in microseconds.
Returns
Allowed byte count; 0 when either flow-control pointer is NULL or no credit of any kind is available.

Feed a new RTT sample into the smoothed estimator and retune.

Ignores NULL state and zero samples. The first sample seeds srtt and sets rttvar to half of it; later samples feed exponential updates (rttvar: 3/4 old + 1/4 deviation, srtt: 7/8 old + 1/8 sample) and then trigger cwist_http2_flow_control_adjust() to recompute network quality, the target window, and the pacing rate.

Parameters
flow_controlConnection flow-control state holding the estimator.
rtt_sample_usMeasured round-trip time in microseconds; must be non-zero to be accepted.

Emit a stream-level WINDOW_UPDATE when enough credit is due.

Server-side only client-initiated (odd, non-zero) streams may receive a stream-level WINDOW_UPDATE; other stream IDs return 0 without emitting anything. Requires at least half the target window in pending credit unless force. When due, the stream target is retuned against the connection's RTT estimate and a WINDOW_UPDATE for the stream is serialized; the stream receive window is credited (saturating at CWIST_HTTP2_MAX_WINDOW), the pending accumulator is cleared, and the update timestamp is advanced.

Parameters
connection_flow_controlConnection flow-control state supplying the RTT estimate.
stream_flow_controlStream flow-control state to update.
bufferDestination buffer for the serialized frame.
buffer_lenAvailable bytes in buffer (at least 13 required).
writtenSet to 0 when no frame is emitted, to 13 on success.
now_usCurrent time in microseconds; drives retuning.
forceEmit the update even when less than half the target window is pending.
Returns
1 when a WINDOW_UPDATE frame was written, 0 when the stream is ineligible or no update is due, -1 when flow_control arguments are NULL or the frame could not be serialized.
