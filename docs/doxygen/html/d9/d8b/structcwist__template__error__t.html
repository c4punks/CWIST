Detailed Description

Optional render diagnostic, owned entirely by the caller.

byte_offset is zero-based within the source named by file_path (or the input string when file_path is empty). Syntax errors point to the opening delimiter of the offending tag. Include I/O and depth errors point to the include tag in its parent source; a top-level file I/O error has offset 0. An include rejected by the include root (CWIST_TEMPLATE_ERROR_FORBIDDEN) also points to the include tag. tag_type is a static string ("variable", "control", "if", "for", or "include"), or NULL when no tag is involved. file_path is copied and NUL-terminated; paths longer than its capacity are truncated. No initialization or cleanup is required. Each diagnostic render call resets every field, including on success.
