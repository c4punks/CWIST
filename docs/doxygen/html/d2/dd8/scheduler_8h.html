size_t cwist_scheduler_cancel_pending ( cwist_scheduler_t *  s,
cwist_scheduler_drop_cb  drop_cb 
)

Cancel all delayed jobs that have not yet fired.

Dequeues every job still waiting on the delayed-job heap. For each job, drop_cb is called with the job's arg so the caller can reclaim any heap-allocated state. If drop_cb is NULL the args are discarded.

Jobs that have already been submitted to the io queue by the timer thread will still run; this function only removes jobs still on the heap.

Safe to call concurrently with cwist_scheduler_schedule(): both operations hold the same mutex.

Parameters
sScheduler whose pending jobs are to be cancelled.
drop_cbOptional destructor called once per cancelled job's arg.
Returns
Number of jobs cancelled.

Detaches the delayed-job heap under s->delayed_mtx and invokes drop_cb(arg) for each cancelled job outside the lock so caller destructors cannot deadlock on scheduler re-entry. Jobs already submitted to the io queue by the timer thread before this call are not affected.

Parameters
sScheduler whose pending jobs are to be cancelled.
drop_cbDestructor called once per cancelled job's arg; may be NULL.
Returns
Number of jobs cancelled.

Create a scheduler with a pool of background workers.

Spawns worker_count worker threads (defaulting to 1 if 0) running the io queue event loop, plus one timer thread for delayed jobs. On any failure, all partially created resources are torn down and freed.

Parameters
worker_countNumber of worker threads; 0 is treated as 1.

Returns
The new scheduler, or NULL on allocation or thread-creation failure.

Schedule a job to run after a relative delay.

Parameters
delay_msMilliseconds to wait before executing the job.
Returns
true on success, false on failure.

Schedule a job to run after a relative delay.

With a zero delay the job is submitted immediately as with cwist_scheduler_submit(). Otherwise it is pushed onto the delayed-job min-heap and the timer thread runs it once the deadline passes.

Parameters
sScheduler to schedule on.
funcJob function to run.
argOpaque argument passed to func.
delay_msDelay in milliseconds before execution; 0 means immediate.
Return values
trueif the job was scheduled.
falseif s or func is NULL, the scheduler is not running, or heap insertion failed (e.g. out of memory).
