◆ cwist_sse_stream_open()

cwist_sse_stream_t * cwist_sse_stream_open ( cwist_http_request *  req)

Upgrade a request connection to a live SSE stream.

Sends the SSE HTTP response headers and marks the request as upgraded, transferring ownership of the connection to the returned stream (release with cwist_sse_stream_close()).

Live streams write to the socket directly, so they are available only on cleartext HTTP/1.x connections. On HTTPS, HTTP/2 and HTTP/3 requests this returns NULL without writing anything, and the handler can answer with a buffered response instead (cwist_sse_response_init() and cwist_sse_response_event()).

Parameters
reqRequest to upgrade; must not be NULL and must not already be upgraded.
Returns
New stream on success, NULL if the request is invalid, arrived over TLS, HTTP/2 or HTTP/3, the headers could not be sent, or the stream could not be allocated.
