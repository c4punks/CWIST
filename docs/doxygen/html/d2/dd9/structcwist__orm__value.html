Detailed Description

One cell of a column-typed result set.

Exactly one payload field is meaningful per cwist_orm_value_type_t: i64 for CWIST_ORM_TYPE_INTEGER (exact above 2^53), real for CWIST_ORM_TYPE_REAL, text for CWIST_ORM_TYPE_TEXT (never NULL), and (blob, blob_len) for CWIST_ORM_TYPE_BLOB (blob is NULL when the BLOB is empty). Owned by the result set; released by cwist_orm_result_free().
