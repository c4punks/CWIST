Detailed Description

Backing state for cwist_scratch_alloc()/CWIST_SCRATCH_DEFER: a single block-scoped allocation that prefers a recycled arena generation and falls back to cwist_alloc() when the request doesn't fit one (see cwist/core/mem/arena.h – only CWIST_ARENA_DEFAULT_GENERATION_BYTES-sized generations hit the zero-libttak-GC recycle path, so cwist_scratch_alloc() always requests the default size and never a custom one).

Zero-initialize before use (= {0}); do not touch fields directly.
