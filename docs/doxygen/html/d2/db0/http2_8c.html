int cwist_http2_push_resource ( cwist_http_request * req,
const char * path,
const char * content_type,
const unsigned char * data,
size_t data_len )

Push a resource to the client (HTTP/2 server push). Sends a PUSH_PROMISE on the request's stream for a fresh server-initiated stream, then responds on that promised stream with a 200 and the supplied body. The :authority pseudo-header is copied from the request's Host header.

Push a resource to the client over HTTP/2 Server Push.

Parameters
reqThe current HTTP/2 request (must have stream_id and private_data populated by the HTTP/2 layer).
pathThe resource path to push (e.g., "/style.css").
content_typeOptional Content-Type header value (may be NULL).
dataResponse body bytes (may be NULL).
data_lenLength of data.
