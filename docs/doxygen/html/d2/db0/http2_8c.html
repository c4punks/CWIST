 Serve one HTTP/2 connection until it closes. Verifies the preface, sends our SETTINGS, then runs the frame dispatcher: HEADERS/CONTINUATION, DATA, SETTINGS, PING, WINDOW_UPDATE, RST_STREAM, and GOAWAY, with per-connection DoS budgets and flow control. A session may be parked off its thread (cwist_https_park) and resumed via conn->proto_state; on exit the session is torn down and proto_state cleared.

Push a resource to the client (HTTP/2 server push). Sends a PUSH_PROMISE on the request's stream for a fresh server-initiated stream, then responds on that promised stream with a 200 and the supplied body. The :authority pseudo-header is copied from the request's Host header.

Push a resource to the client over HTTP/2 Server Push.

Parameters
reqRequest of the stream that triggered the push; its private_data must be the cwist_https_connection.
path:path for the promised request.
content_typeOptional content-type header value.
dataBody bytes (may be NULL when data_len is 0).
data_lenBody length.
Return values
0Response queued/written successfully.
-1Invalid arguments, missing Host header, or send failure.
