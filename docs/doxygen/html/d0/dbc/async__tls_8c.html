Detailed Description

Dispatch-thread record of a deferred-response handoff.

cwist_async_defer() records the handle it created here, on the dispatch thread. Dispatch decides the handoff from this record instead of res->deferred/res->async, which a producer on another thread can reach and overwrite before the ack (#344). Kept apart from async.c so that http.c and the middleware can use it without linking the completion machinery.

◆ cwist_async_dispatch_take()

cwist_async * cwist_async_dispatch_take ( cwist_http_response *  res)

Dispatch side of the handoff: return the handle cwist_async_defer() created for res on this thread, or NULL if the handler did not defer it, and forget it. Dispatch calls this right after the handler returns and uses the result instead of res->deferred/res->async, which a producer can reach and overwrite before the ack. A mismatch between the two is reported (and aborts under CWIST_ASYNC_STRICT=1).
