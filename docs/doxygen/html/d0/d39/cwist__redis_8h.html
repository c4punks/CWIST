◆ cwist_redis_reply_t

typedef struct cwist_redis_reply cwist_redis_reply_t

Parsed RESP2 reply tree.

Supported since v3.8. Returned by cwist_redis_command_argv_reply(). type is the RESP type byte: '+', '-', ':', '$', '*'. For '-', str holds the error text and the command reports failure. For ':' and '$', str is the textual value (always NUL-terminated; use len for exact bulk length) and integer holds the parsed number. For '*', element/elements hold children.

Authenticate/select a logical Redis database on this connection.

Warning
AUTH credentials are sent over plaintext TCP (RESP has no encryption by itself). Only use this over loopback, a trusted private network, or behind a TLS-terminating proxy (stunnel/spiped) in front of Redis.

Authenticate against the server with ACL-style (username, password) or legacy (password-only) AUTH.

Parameters
rConnection handle.
usernameOptional ACL username; NULL selects password-only AUTH.
passwordPassword (required).

Subscribe to channels on a dedicated connection.

This call blocks the current thread and invokes cb for each message. Use it inside a background thread. To stop, call cwist_redis_close() from another thread (the read loop will exit on socket error).

Parameters
rConnection. Must not be shared with other commands.
channelsNULL-terminated array of channel names.
cbMessage callback.
ctxUser context forwarded to callback.
Returns
0 when stopped cleanly, -1 on error.

Subscribe to channels and run a blocking message loop, invoking the callback for each incoming message.

Parameters
rConnection handle.
channelsNULL-terminated list of channel names.
cbCallback invoked as cb(channel, message, ctx) per message.
ctxOpaque pointer passed through to the callback.
Returns
Zero error value; the loop ends when the connection is shut down (see cwist_redis_close()).
