Detailed Description

mbedTLS TLS backend: HMAC subset (HMAC-SHA256, one-shot + streaming).

Part of the CWIST TLS backend seam; see shim/openssl/ssl.h for the design. Backs signed session cookies (session.c), sequenced-chunk authentication (seq_auth.c) and JWT HS256.
