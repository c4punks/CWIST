)

Create an authenticated-sequencing context.

Allocates the context plus the nonce and completed-message-id replay caches, each sized to replay_window entries. On failure all partially allocated state is freed and NULL is returned. The returned context is owned by the caller and must be released with cwist_seq_auth_context_destroy().

Parameters
key32-byte authentication key, copied into the context.
session_id16-byte session identifier, copied into the context.
replay_windowNumber of nonces/message ids to remember for replay detection; must be non-zero and small enough that window * 28 does not overflow size_t.
Returns
New context, or NULL on invalid arguments or allocation failure.

Record a message id as fully received.

Adds the message id to the completed-message replay cache so any later chunk claiming that id is rejected by cwist_seq_auth_unwrap(). Duplicate ids are ignored. Safe to call with NULL; otherwise takes the context lock.

Parameters
ctxAuthenticated-sequencing context, or NULL.
message_id16-byte message id to record.

Verify, authenticate, and split an incoming authenticated chunk.

Validates the chunk layout, recomputes the HMAC-SHA256 tag (compared in constant time), and rejects replays by checking the nonce and message id against the context's replay caches under the context lock; a fresh nonce is recorded in the cache on success. Chunks of fully completed messages can be rejected by recording their ids with cwist_seq_auth_mark_complete().

Parameters
ctxAuthenticated-sequencing context.
dataWire-format authenticated chunk.
lenLength of data in bytes.
metadataReceives the verified message id and nonce.
chunkReceives the parsed chunk header and a payload pointer into data; untouched on failure.
Return values
trueThe tag is valid and the chunk is not a replay.
falseInvalid arguments, malformed chunk, bad tag, or replayed nonce/message id.

Attach message id, nonce, and authentication tag to a chunk.

Builds the wire-format authenticated chunk (sequence header || message id || nonce || payload || tag) without modifying the caller's chunk. The tag is an HMAC-SHA256 truncated to CWIST_SEQ_AUTH_TAG_SIZE over the session id and the header/payload contents. The output buffer is owned by the caller and must be freed with cwist_free().

Parameters
ctxAuthenticated-sequencing context.
message_id16-byte message identifier to embed.
nonce12-byte nonce to embed.
chunkBuffer holding one sequence chunk (header + payload).
chunk_lenLength of chunk in bytes.
outReceives a newly allocated wire-format chunk on success.
out_lenReceives the wire chunk length on success.
Return values
trueThe chunk was authenticated and wrapped.
falseInvalid arguments, malformed chunk, allocation failure, or tag computation failure; no output is produced.
