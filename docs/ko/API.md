# CWIST API 문서

CWIST 라이브러리 레퍼런스에 오신 것을 환영합니다. 아래 모듈 색인에서 시작하거나, 함수
시그니처만 필요하다면 [간단 레퍼런스](api-quickref.md)로 바로 이동하세요.

## 모듈

*   **[프레임워크와 앱](api/app.md)**: 고수준 애플리케이션 추상화와 라우팅.
*   **[HTTP 코어](api/http.md)**: 저수준 HTTP 구조체와 파싱.
*   **[HTTPS](api/https.md)**: 보안 SSL/TLS 전송 계층.
*   **[데이터베이스](api/sql.md)**: SQLite3 데이터베이스 래퍼.
*   **[쿼리와 URI](api/query.md)**: 쿼리 문자열 파싱과 URI 유틸리티.
*   **[SString](api/sstring.md)**: 안전한 동적 문자열 처리.
*   **[JSON](api/json.md)**: JSON 생성과 복구(healing) 도우미.
*   **[HTML 컴포넌트](api/html.md)**: 재사용 가능한 HTML 렌더 단위, 컴포넌트 범위 CSS, 페이지/프래그먼트 응답.
*   **[미들웨어](api/middleware.md)**: 미들웨어 파이프라인과 내장 미들웨어.
*   **[WebSocket](api/websocket.md)**: WebSocket 업그레이드와 프레이밍.
*   **[Server-Sent Events](api/sse.md)**: 이벤트 스트림 응답과 실시간 스트림.
*   **[쿠키](api/cookie.md)**: Cookie 헤더 파싱과 Set-Cookie 생성.
